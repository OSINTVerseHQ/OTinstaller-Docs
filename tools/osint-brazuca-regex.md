# Osint Brazuca Regex

Repositrio criado com intuito de reunir expresses regulares dentro do contexto Brasil.

## Source

- Repository: https://github.com/osintbrazuca/osint-brazuca-regex
- License: MIT

## Install

```bash
otinstaller install osint-brazuca-regex
```

otinstaller clones `https://github.com/osintbrazuca/osint-brazuca-regex.git` at ref `5ec05893330bc90314796787bbf17a97301f9404` into a dedicated virtualenv, then installs the dependencies listed in `requirements.txt`.

## Credentials

No API keys needed.

## Run

```bash
otinstaller run osint-brazuca-regex -- --help
```

Results are saved to `./results/osint-brazuca-regex/<target>/`.
